# ReXGlue evaluation patches

These separate candidate changes apply to ReXGlue revision `c94f5ebdcb3c9d1a460ca48e04f9758448f8d518`. They are retained for reproducible evaluation, not permanent dependency adoption. All ten patches pass sequential application checks against that revision in the order recorded in `manifest.json`. Apply `gapfill-backward-exit.patch` before `gapfill-indirect-terminator.patch`; both modify the same partitioner. Apply `clock-timing.patch` after `chrono-range.patch`; both modify clock headers.

- [chrono-range.patch](chrono-range.patch): preserve 100-nanosecond clock range, validate calendar recomposition, and add boundary/actual-export tests. Tracked by [issue 7](https://github.com/RealAmethyst/BakuganBattleBrawlersRecomp/issues/7).
- [depfile-expectations.patch](depfile-expectations.patch): correct expected escapes and add dollar-sign coverage; production escaping is unchanged. Tracked by [issue 8](https://github.com/RealAmethyst/BakuganBattleBrawlersRecomp/issues/8).
- [scalar-layout.patch](scalar-layout.patch): consistently require and enable the shader uniform layout on Vulkan core and extension paths. The [diagnostic-launch record](../../diagnostic-launch.md) owns the 19-case device-contract checks and build evidence. Tracked by [issue 10](https://github.com/RealAmethyst/BakuganBattleBrawlersRecomp/issues/10).

- [gapfill-backward-exit.patch](gapfill-backward-exit.patch): discover leaves following backward gap exits. [Issue 9](https://github.com/RealAmethyst/BakuganBattleBrawlersRecomp/issues/9) records local candidate verification; [gapfill-regressions.cpp](gapfill-regressions.cpp) is the original 21-case standalone fixture, including all ten earlier cases. It accepts an output JSON filename and runs the actual Scan/Discover/GapFill/Merge/Validate phases. Build it against the pinned SDK codegen/test-support headers and libraries; compare baseline linkage with the candidate phase object linked before librexcodegen. Exact toolchain/link commands remain in the private evidence collection. The fixture was extended with indirect-tail, conditional, linked-call and switch-ownership controls.

- [gapfill-indirect-terminator.patch](gapfill-indirect-terminator.patch): discover unseeded leaves following unconditional CTR tails. The 21-case fixture passes 17 cases before and all 21 after this addition. [Issue 13](https://github.com/RealAmethyst/BakuganBattleBrawlersRecomp/issues/13) and the [first-launch failure record](../../first-launch-failure.md) own the crash trace, registration audit and replacement build.
- [emitting-owner.patch](emitting-owner.patch): classify emitted branches using the known function entry when instruction-address lookup is ambiguous. [emitting-owner-regressions.cpp](emitting-owner-regressions.cpp) drives actual C++ emission through 12 original cases: baseline 8/12, candidate 12/12, including a deliberately unresolved target that retains its error. It accepts an output directory. Tracked by [issue 14](https://github.com/RealAmethyst/BakuganBattleBrawlersRecomp/issues/14).

- [clock-timing.patch](clock-timing.patch): preserve fractional counter progress and ordered sampling, correct signed and scaled deadline conversions, and align Linux counter units with frequency. [clock-timing-regressions.cpp](clock-timing-regressions.cpp) compiles actual SDK clock sources with controlled clock/configuration support in `clock-test-support`. [Issue 16](https://github.com/RealAmethyst/BakuganBattleBrawlersRecomp/issues/16) and the [timing record](../../timing-contracts.md) own the 66-case results, arithmetic reference checks and real-runtime stress comparison.
- [alertable-zero-readiness.patch](alertable-zero-readiness.patch): inspect ready objects before returning timeout from expired alertable POSIX waits. [alertable-readiness-regressions.cpp](alertable-readiness-regressions.cpp) links the actual runtime and preserves APC priority and existing wait semantics; baseline 22/31, candidate 31/31. Tracked by [issue 17](https://github.com/RealAmethyst/BakuganBattleBrawlersRecomp/issues/17).
- [presentation-timing.patch](presentation-timing.patch): optional cumulative swap/placeholder and Vulkan acquire/present diagnostics, disabled by default in the SDK and enabled by the diagnostic host. Records CPU/API observations, not physical scanout or GPU execution time. The [timing record](../../timing-contracts.md) owns verification and limits.

- [idle-toast-repaint.patch](idle-toast-repaint.patch): stop empty achievement notifications from driving continuous UI repaint, retain ordinary-dialog wake/animation, and marshal notification ownership onto the UI thread. [Issue 19](https://github.com/RealAmethyst/BakuganBattleBrawlersRecomp/issues/19) and the [timing record](../../timing-contracts.md) own the 33-case actual-method synthetic checks, independent review and integration evidence. Exact fixture generation, commands and source hashes are retained in the private evidence collection. This changes UI class layouts; rebuild the runtime and every application/plugin consumer together. Windows/macOS execution remains untested.

The [first-build report](../../first-build-gates.md) owns gap-fill, generated-code compilation and graphics/audio results. The [trial report](../../linux-toolchain-trial.md) owns build/test results and limitations. Patch identities are in [manifest.json](manifest.json). Apply to a separate checkout at the stated revision; retain the unmodified baseline for comparisons. No game inputs are involved.

## Compatibility limits

Additional original fixtures: [scalar-layout-regressions.cpp](scalar-layout-regressions.cpp) drives the actual baseline/candidate device code using synthetic Vulkan function pointers; [synthetic-xma.c](synthetic-xma.c) decodes generated silent XMA frames with the pinned FFmpeg archives. They contain no game input. Exact private build commands and limits are recorded in the diagnostic-launch evidence collections. The XMA fixture follows the decoder's own grammar and is not an independent codec-conformance test.

The gap-fill change is a local partitioning candidate, tested by object replacement, synthetic ownership controls and private target compilation. It does not prove every function boundary or instruction semantic. Both codegen fixtures are original synthetic code with no game inputs or private paths. The gap-fill fixture exercises discovery; the emitter fixture isolates known graph ownership. Manual switch fixtures do not establish automatic switch recognition.


The earlier `chrono-range.patch` supports absolute FILETIME values from zero through `INT64_MAX`. Unsupported negative/upper-half inputs can still overflow unchecked low-level conversions; it is not an arbitrary-input safety fix. The void time-to-fields export's behavior for invalid inputs remains unresolved.

`to_sys` returns `sys_time<hundrednanoseconds>`. External callers requiring the host clock's native duration must check range and cast explicitly where needed. Native Windows/macOS builds have not been tested. Four upstream BitStream tests remain skipped.
